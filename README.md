# Capgemini Hiring Assessment Preparation

A concise and structured preparation repository for candidates appearing in Capgemini's updated recruitment assessment. It covers all stages: Technical MCQs & AI Literacy, 20-Minute Code Debugging, 45-Minute AI-Assisted Coding, Cognitive Puzzles & Behavioral Profiling, and Spoken Communication.

Prep material, not the official syllabus. Real questions can differ.

## Who It Is For
Students and software engineers preparing for Capgemini's on-campus and off-campus recruitment drives.

## Study Order
Follow the preparation sequence in this order:
`01 format -> 02 MCQs -> 03 debugging -> 04 AI coding -> 05 cognitive -> 06 communication -> CHEATSHEET`

## Repository Structure
- [01-exam-format](01-exam-format/README.md) - Assessment structure, stage durations, elimination cutoffs, and what each section tests.
- [02-ai-literacy-and-cs-mcqs](02-ai-literacy-and-cs-mcqs/) - High-yield technical MCQs and AI literacy questions with shortcuts and traps.
- [03-code-debugging](03-code-debugging/) - 20-minute code debugging strategy, 10-point scanner, and line-by-line bug walkthroughs.
- [04-ai-assisted-coding](04-ai-assisted-coding/) - 45-minute coding patterns (sliding window, prefix sums, hash maps) and token-efficient AI prompts.
- [05-cognitive-and-behavioral](05-cognitive-and-behavioral/) - Walkthroughs and shortcut tricks for Motion Challenge, Bubble Memory, Deductive Logic, and Behavioral profiling.
- [06-communication](06-communication/) - Automated spoken communication round rules, SVAR/Versant evaluation criteria, and speaking formulas.
- [RESOURCES.md](RESOURCES.md) - Verified video walkthroughs, unverified reference videos, and allowed LeetCode practice links.
- [COVERAGE.md](COVERAGE.md) - Progress checklist tracking every topic and question against source requirements.
- [CHEATSHEET.md](CHEATSHEET.md) - One-page master summary for rapid last-minute revision (created in Phase 6).
