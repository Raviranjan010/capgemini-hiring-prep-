# Capgemini Hiring Assessment Preparation

A concise and structured preparation repository for candidates appearing in Capgemini's updated Exceller recruitment assessment. It covers all stages: AI Literacy & GenAI (20 min), Technical MCQs & Pseudo-code (20 min), 20-Minute Code Debugging, AI-Assisted (Vibe) Coding, Cognitive Puzzles & Behavioral Profiling, and Spoken Communication.

Prep material, not the official syllabus. Real questions can differ.

## Who It Is For
Students and software engineers preparing for Capgemini's on-campus and off-campus recruitment drives.

## Study Order
Follow the preparation sequence in this order:
`01 format -> 02 MCQs -> 03 debugging -> 04 AI coding -> 05 cognitive -> 06 communication -> CHEATSHEET`

## Repository Structure
- [01-exam-format](01-exam-format/README.md) - Capgemini Exceller assessment blueprint, section strategy checklists, and exam walkthroughs.
- [02-ai-literacy-and-cs-mcqs](02-ai-literacy-and-cs-mcqs/) - High-yield technical MCQs, operator precedence, and GenAI literacy questions with shortcuts and traps.
- [03-code-debugging](03-code-debugging/) - 20-minute code debugging strategy, 10-point scanner, undirected graphs, DP knapsack, and line-by-line bug walkthroughs.
- [04-ai-assisted-coding](04-ai-assisted-coding/) - Interactive coding patterns (Decode Ways, Coin Change, sliding window, prefix sums, tree LCA, parity, and string reductions) with token-efficient AI prompts.
- [05-cognitive-and-behavioral](05-cognitive-and-behavioral/) - Walkthroughs and shortcut tricks for Motion Challenge, Bubble Memory, Deductive Logic, and Behavioral profiling.
- [06-communication](06-communication/) - Automated spoken communication round rules, SVAR/Versant evaluation criteria, and speaking formulas.
- [RESOURCES.md](RESOURCES.md) - Verified video walkthroughs, unverified reference videos, and allowed LeetCode practice links.
- [COVERAGE.md](COVERAGE.md) - Progress checklist tracking every topic and question against source requirements.
- [CHEATSHEET.md](CHEATSHEET.md) - One-page master summary for rapid last-minute revision (created in Phase 6).
