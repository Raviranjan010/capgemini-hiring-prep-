# Capgemini Recruitment Assessment Format

## Assessment Stages Overview

| Stage | Section Name | Duration | Nature & Rules | Elimination / Cutoff |
| :---: | :--- | :---: | :--- | :--- |
| **Stage 1** | Technical MCQs + AI Literacy | 50 min | 40 MCQs covering CS fundamentals and GenAI | Elimination; 15 to 18 correct [UNVERIFIED] |
| **Stage 2** | Code Debugging | 20 min | 1 problem; all public and hidden test cases must pass | Elimination; 100% test cases passed |
| **Stage 3** | AI-Assisted Coding | 45 min | 1 problem; algorithmic problem solving with AI assistance | Evaluation; correctness and optimal prompting |
| **Stage 4** | Cognitive and Behavioral Assessment | ~68 min total | 4 modules (detailed below) | Profiling; non-elimination (consistency check) |
| ↳ 4a | Motion Challenge | 6 min | Gamified spatial puzzle (obstacle clearing in min moves) | Evaluated on speed and move optimality |
| ↳ 4b | Bubble / Grid Memory | 12 min | Rapid sequential visual recall game | Evaluated on recall accuracy |
| ↳ 4c | Deductive Reasoning | 25 min | Formal logic, syllogisms, and contrapositive reasoning | Evaluated on logical correctness |
| ↳ 4d | Behavioral / Adaptive | 25 min | Forced-choice work preference statements | Non-elimination profiling (checks consistency) |
| **Stage 5** | Spoken Communication | ~30 min [UNVERIFIED] | SVAR / Versant style audio evaluation (headphones required) | Qualifying; automated speech scoring |

## What Each Section Tests
- **Technical MCQs + AI Literacy**: Tests core computer science fundamentals (OS, DBMS, SQL, OOPs, Networking, Pseudocode) and modern Generative AI / LLM literacy concepts.
- **Code Debugging**: Tests rapid code scanning, syntax and logical error identification, and edge-case correction under tight time constraints.
- **AI-Assisted Coding**: Tests data structures and algorithmic mastery (sliding window, prefix sum + hash maps) alongside token-efficient AI prompt structuring.
- **Cognitive and Behavioral**: Tests spatial planning (Motion Challenge), short-term visual working memory (Bubble Memory), formal propositional logic (Deductive Reasoning), and corporate workplace competency alignment and integrity (Behavioral Profiling).
- **Spoken Communication**: Tests English listening comprehension, pronunciation, fluency, sentence mastery, and structured impromptu speech articulation.
