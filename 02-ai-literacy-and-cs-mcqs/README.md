# AI Literacy & Computer Science MCQs

This module covers foundational Generative AI literacy and recurring core CS topics tested in Capgemini's 40-MCQ technical assessment.

## Module Files
1. [01_ai_literacy.md](01_ai_literacy.md) - GenAI foundations, GenAI vs SQL ("Librarian vs Author"), LLM architecture pipeline, RTC-FC prompt framework ("Run To Catch Fast Cars"), Transformers, embeddings, RLHF, RAG architecture, and 23 practice MCQs.
2. [02_networking_sql_dbms.md](02_networking_sql_dbms.md) - Subnet calculations, SQL three-valued logic (`NULL`), `WHERE` vs `HAVING`, second highest salary queries, and self joins.
3. [03_oops_os.md](03_oops_os.md) - C++ diamond problem & virtual inheritance, shallow vs deep copy, vtables, Coffman deadlock conditions, Banker's algorithm, and page replacement policies.
4. [04_pseudocode_and_bitwise.md](04_pseudocode_and_bitwise.md) - Operator precedence with bit shifts, static variable recursion traces, rightmost set bit isolation (`n & -n`), and bit tricks.
